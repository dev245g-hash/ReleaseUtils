# 🛠️ Useful Freeware Tools Repository
This repository is a space for distributing individually developed utility programs.
You can download the latest version of each tool from the **Releases** section on the right.

### 📦 Tool List
| Program | Description | Download |
| :--- | :--- | :--- |
| **MultiCapture** | A portable, tray-based capture & screen-recording tool.<br>One PrintScreen grabs a region, window, monitor or full screen — or starts a region recording to MP4 (system sound + mic, pause, and move the region while it rolls).<br>Dashcam mode keeps the last 20–60s running in the background, so you can save what already happened.<br>Element-level window capture · non-destructive editor (curved arrows, screen color picker, style presets) · fully portable (no registry, no install).<br><img width="410" height="280" alt="MultiCapture-demo" src="https://github.com/user-attachments/assets/77b00428-7c77-4d1b-923c-c779a7b859fd" />| [Download](https://github.com/dev245g-hash/ReleaseUtils/blob/main/MultiCapture.md) |
| **MultiView** | A portable multi-view workspace that tiles web pages and local folders into one grid.<br>Type an address and the cell picks its own engine — `https://…` opens a Chromium (WebView2) web view, `C:\…` opens a folder view — up to a 9 × 9 grid with row/column spans.<br>Drag the gap between cells to change split ratios, and the whole board (addresses, zoom, ratios, window position) comes back exactly as you left it.<br>Visual layout editor (drag to move · swap · resize · keyboard editing) · fully portable single exe (no registry, no install).<br><img width="400" height="250" alt="image" src="https://github.com/user-attachments/assets/9b6f7cbc-7007-44f9-a807-2d809558d93f" />| [Download](https://github.com/dev245g-hash/ReleaseUtils/blob/main/MultiView.md) |
